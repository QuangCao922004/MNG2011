# ADLC workspace

Read `kit/core/AGENTS.template.md` before substantive work. Resolve its toolkit prefix `adlc-kit/` to `kit/` in this folder. The operational project root is `workspace/`. Keep work state and all plan, research, report and docs artifacts under that operational root. Use `node run.mjs work ...` for the workbench and `index.html` as the main dashboard.

The original startup modes, role contracts, skill registry, human-approved delegation and evidence gates apply. Root initialization configures local files. Host harness, Python, Docker and credentials require their own availability checks.
